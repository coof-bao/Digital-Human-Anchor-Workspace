# V3 商家端页面级方案（基于 V2 链路迭代）· 讨论稿

> 双端原则（最高优，见规则 `digital-human-live-baseline.mdc`）：本文档**只**描述 🧑‍💼 商家端＝流程与 UI 体验 + 商家必要输入 + 每步操作埋点回流。所有"脚本怎么生产 / 怎么自动迭代 / provenance / diff / prompt / 归因"一律不在商家端出现，归 🏭 平台端。

---

## §0 设计硬约束（先读，全文适用）

| 约束 | 内容 |
|---|---|
| **不重构链路** | 维持 V2「`← Create AI LIVE` + 顶部 Stepper + 左/中工作区 + 右侧 9:16 Preview + 底部 Save/Previous/Next」五步壳，V3 只在**步内做增量**，不改步骤数、不改跳转顺序 |
| **配色** | 主色/主按钮/选中态/完成态＝**Teal**；顶导黑；`Go live now` 红；信息引导 banner 浅绿底；Tips 气泡 浅蓝/紫；状态色 Live 红粉 / Ready 绿 / Generating 蓝 / Ended 灰 / Draft 琥珀。**不得引入新色**。 |
| **组件** | 一律复用 V2：可选卡片（选中＝teal 边框+右上 ✓，hover 删除）/ 缩略图右下时长 badge / 可编辑标题 ✏️ / 二选一 radio 互斥+二次确认 / 拖拽 ⠿ / 浅绿信息 banner（可 ×）/ Tips 帮助卡 / 上传 dropzone（虚线+↑+规则提示）/ 破坏性操作二次确认弹窗 / Toast / 分页 `A total of N`+`10/page`。新功能必须**套用既有组件**，不新造控件。 |
| **语言** | UI 默认英文；脚本区保留 `Show scripts in Chinese` 切换；命中违禁词正文 highlight。 |
| **图片识别** | 凡画面/图片识别（素材封面理解、自动分镜、人格卡品类匹配、背景图生成）→ 一律 `gemini-3-pro-preview-new`（ModelHub 内网）。这些**全在平台侧异步发生**，商家端只看结果（缩略图/标签/进度），**不暴露模型与过程**。 |
| **预览** | 右侧 9:16 手机壳沿用 V2：顶 13% 平台 UI、底 17% 评论购物车安全区，数字人不被遮挡。 |

**V3 商家端可感知迭代清单（其余对商家无感）**：
1. **Step1**：数字人选择升级为**人格卡画廊**（品类标签 + 筛选器）；新增 **Market（直播国家，本期 US）+ Language（直播语言：English / Spanish）**，语言**联动过滤数字人画廊**（只露支持该语言的形象/音色）。
2. **Step2 完成后**：新增**「双模式」全屏二选一卡片**——🅐 **经典分步模式（Classic）** / 🅑 **智能剧本模式（Smart Storyboard）**；新商家默认模式一、**本场选定后不可切换**。
3. **模式一（P0）**：**`Set up scenes` 与 `Generate scripts` 合并为一页工作台 `Set up scenes & scripts`**（Log 0035 拍板）——左商品流、中 Scene 卡（改/删卖点 + 数字人讲/用你的视频 + **内嵌可编辑话术**，含「✨ 重新生成」进度条）、右 Preview & Layout（数字人/前景三层微调）；步骤条由 5 步收敛为 **4 步**（Step1 → Step2 → 选模式 → Set up scenes & scripts → Render）。脚本＝**V2 既有脚本生成能力**；术语仍用 **Scene**。
4. **模式二（P2）**：把 Step3 Set up scenes + Step4 Generate scripts **合并为一步 = LIVE Storyboard（timeline 视图）**，画面/口播/互动/运营/声音/场外音多轨对齐时间轴；由**平台端 Script Studio 主-子 Agent 编排**驱动（架构先设计、实现后置 P2）。
5. **散落字段**：禁讲内容、商家备注、整场流程偏好、Market/Language（见各步「商家输入新增」）。

> **优先级标签（本文档逐模块标注 · Log 0025）**：`【P0】`＝模式一 + 平台端素材加工；`【P1】`＝平台端归因/诊断（商家无感）；`【P2】`＝模式二智能剧本（架构预留、实现后置）。
> **两模式同产一份「直播大脑 JSON」、平台端生产不分叉**；模式仅商家端编辑形态差异（平台端轻感知 `mode` 字段用于归因，见平台端方案）。

## §3 Step 1 · Set up LIVE — 数字人**人格卡画廊** + **直播国家/语言**（核心增量① · 【P0】）

**V2 现状**：LIVE name 输入 + 数字人卡片网格（试听 `Listen 3s` + 音色风格 Tag）+ 背景（Background templates / My own image 两 Tab）+ 右侧 9:16 预览 + Save/Next。

**V3 增量**：① 顶部新增 **Market + Language** 两个选择（决定下游脚本/素材语言）；② 数字人卡片网格升级为**人格卡画廊**，沿用 V2 可选卡片组件，维持"先选人"流程（Log 0009）；③ **语言联动过滤画廊**。

### UI 展示逻辑（中栏 · Set up LIVE，自上而下，控件全部沿用 V2）
**① LIVE basics（沿用 V2 表单区）**
- `LIVE name`：单行文本输入（V2 既有）。
- 🆕 `Market ▾`（直播国家，下拉，沿用 V2 下拉组件）：本期**仅 `United States (US)` 单选**且默认选中、置灰不可改（结构为未来多国预留）。右侧带国旗/缩写。
- 🆕 `Language ▾`（直播语言，下拉）：两项 **`English` / `Spanish`**，默认 `English`。**ⓘ 帮助气泡**（V2 Tips 组件）说明"决定口播语言与可用数字人，一场一种语言不可混播"。
  - **联动**：切换 Language → **下方人格卡画廊即时过滤**，仅显示支持该语言口播的形象/音色；若当前已选数字人不支持新语言 → 二次确认弹窗（V2 既有）提示将清空已选数字人。

**② Choose avatar hosts（人格卡画廊）**
- **筛选器条**（卡片网格上方，沿用 V2 表格筛选样式）：
  - 品类下拉 `Category ▾`（Beauty/Skincare、Wig/Hair、Fashion/Apparel、Home/Kitchen、Electronics、Mom&Baby、Pet…）。**默认值由平台预选**：优先取该商家**注册时的主营类目**，无则取**近 30 天动销额最大的主营类目**；商家可改。
  - 族裔 `Ethnicity ▾`、价格带 `Price tier ▾`（来自人格卡字段）。**语言不在此处选**（已上移为 `Language ▾` 并联动过滤）。
  - 右侧 `See more`。
- **人格卡**（V2 可选卡片，选中＝teal 边框+右上 ✓，hover 不需删除）每张含：
  - 数字人头像/底板缩略图（右下角无时长 badge）+ 姓名（英文名 + 中文音译副行）
  - **一句话定位**（人格卡字段，如"亲和力强的家居好物分享者"）
  - **品类标签 Tag**（teal 浅底 pill，可多个）+ 价格带 Tag + **语言能力 Tag**（`EN` / `ES`）
  - **试听按钮** `▶ Listen`（V2 既有，电商场景 demo）+ 音色风格 Tag（cheerful/bright…）
- 选中后右侧 9:16 预览实时换成该数字人底板。

**③ Set up LIVE background（背景，沿用 V2 两 Tab）**：`Background templates` / `My own image`，可选卡片 + `See more` + 上传 dropzone（规则前置提示）。**此处即"全局背景"入口**（详见下「商家输入新增」）。

**④ 底部操作条**：`Save`（次）/ `Next`（teal 主，右下）。

### 商家输入新增
- 🆕 **Market（US，本期固定）+ Language（English / Spanish）**：**核心前置输入**——决定下游脚本口播语言、合规口径、素材 ASR/打标语言、数字人音色选择（进平台端 `shared_context.market / language`）。**一场一语言不可混播**（Log 0022）。
- LIVE name（V2 既有）。
- 数字人形象选择（V2 既有，体验升级为人格卡；受 Language 联动过滤）。
- 背景（V2 既有，`My own image` 上传规范前置提示不变）。**此处即"全局背景"设置入口**：除背景图外，V3 支持上传**直播间维度的背景视频**（贯穿整场、循环播放），Step3 不再重复设全局背景。

### 图片识别点（平台侧，商家无感）
- 人格卡的"品类标签/适配建议"由平台侧用 `gemini-3-pro-preview-new` 对底板画面 + 人格设定预生成并入库；商家端只读标签。
- 背景图生成（默认结合所选商品出 4 张）＝ V2 既有 P0 算法，渲染侧能力不变。

**埋点回流**：`s1_market_set`（国家，本期恒 US）、`s1_language_set`（en/es）、`s1_avatar_filter_change`（品类/ethnicity/价格带）、`s1_avatar_listen`（avatar_id、时长）、`s1_avatar_select`（avatar_id、是否经筛选命中、语言是否匹配）、`s1_bg_select` / `s1_bg_upload`、`s1_global_bg_set`（类型 image/video）。

## §4 Step 2 · Select product（选品）· 增量（轻）【P0】

**V2 现状**：`+ Add products` + 表格（Product 图+名+`ID` / Price / Stock / Item sold / Remove）+ Save/Previous/Next。

**V3 增量**：保持 V2 选品表格链路**不变**。**核心原则**：作为 TikTok Shop US 平台方，商家在架可售的商品平台数据库**全部覆盖**——商家选完商品后，**商品标题 / 价格 / 品类 / 描述 / 图片 一律不需要商家填写**，平台结合所选商品从**商品数据库自动带出**，回填进最终 JSON。**不存在"库里没有的品"，故全程无任何商品信息手填入口。** 商家端只做"选品 + 卖点/禁讲两处选填增强"：

- **A. 选品**（V2 既有 `+ Add products`）：选中后**图/名/ID/Price/Stock/品类/描述/图片** 全部由商品库**自动带出**，商家**零填写**，展开行只读展示（可纠错但非必填）。
- **B. 卖点 / 禁讲（唯一两处商家"可选输入"，强烈建议填）**：行内点 `▸` 展开 **More settings**，仅承载两列：
  - **Selling points / 卖点备注**（选填、强烈建议填）——"必须讲的卖点"。商家最懂自家商品，填得越全脚本越准。⭐ **Log 0036：选品表卖点改为可编辑**——已有卖点可改/可删，并可「+ 加卖点」内联输入；商家主动补充的卖点**回流平台**用于生成话术（埋点 `s2_selling_point_edit`）。
  - **Do-not-say / 禁讲内容**（多行文本，选填、强烈建议填，红色 ⓘ"将作为合规与生成约束"）——"不能讲的"。
  - 📌 价值锚点（记忆库）：卖点/禁讲连同人群洞察沉淀进**商家记忆库**复用。例：英国卖 57 英镑手机，直播间常问"能否在非洲用"，回查留评账号多为非洲用户→沉淀"非洲专场"文案因子，下次自动复用。

> 卖点/禁讲是商家端"可选必要输入"，**消费方在平台端**（进解析与生成 prompt 约束、合规左移 + 记忆库沉淀），商家端只采集、不展示如何被使用。

**埋点回流**：`s2_product_add` / `s2_product_remove` / `s2_sellingpoints_edit`（product_id、字数）/ `s2_donotsay_edit`（product_id、字数）。（商品信息全部由平台带出，无商家编辑埋点）

## §4.5 模式选择 · **双模式全屏二选一卡片**（Step2→Step3 之间 · 核心增量）

**触发时机**：Step2 选品完成、点 `Next` 离开 Step2 时，**全屏覆盖一张二选一卡片页**（非弹框、占满工作区，沿用 V2 卡片视觉 + teal 选中态），让商家本场二选一。**新商家默认高亮模式一**；**本场一旦进入后续步骤即锁定，不可中途切换**（Log 0023）。

### UI 展示逻辑（全屏 · Choose your scripting mode）
- 顶部标题 `Choose how you build this LIVE` + 副标题 `You can't switch modes for this LIVE after you continue.`
- **左右两张大卡（V2 可选卡片放大版，左右并排，选中＝teal 边框+✓）**：

| | 🅐 **Classic · 经典分步【P0】** | 🅑 **Smart Storyboard · 智能剧本【P2】** |
|---|---|---|
| 角标 | `Recommended for new sellers` | `Advanced` |
| 一句话 | 一页工作台搭：选品→（场景＋脚本同页）→开播 | 一个时间轴搞定：场景＋脚本合并编排 |
| 流程缩略图 | **Set up scenes & scripts（场景+脚本合并页）** → Step5 | LIVE Storyboard(timeline) → Step5 |
| 适合 | 想要可控、熟悉 V2 的商家 | 想要一屏掌控全场画面/口播/互动节奏的进阶商家 |
| 底部按钮 | `Use Classic`（teal 主按钮） | `Use Smart Storyboard`（teal 主按钮） |

- 选中任一卡 → 进入对应 Step3。底部 `Previous` 可退回 Step2。
- 模式二若当前为 P2 未上线：卡 🅑 置灰 + `Coming soon` 角标，仅展示不可选（架构预留）。

**埋点回流**：`mode_card_view`、`mode_select`（mode=classic/smart、是否新商家默认、是否被改）。**`mode` 写入该场 `shared_context.mode`**，贯穿后续所有埋点与平台端归因（详见平台端方案 §mode 字段）。

## §5 Step 3 · Set up scenes — `Background`/`Use your video` 点开**素材库弹框**（核心增量② · 【P0】模式一 / 模式二合并入 Storyboard）

> ⭐ **Log 0035 起：模式一已把本节（Set up scenes）与 §6（Generate scripts）合并为同一页工作台 `Set up scenes & scripts`**——本节描述的 Scene 卡（左商品流 / 中 Scene 卡 / 右 Preview & Layout 三层微调）与 §6 的可编辑话术**同屏呈现**，每个 Scene 卡内直接内嵌该 Scene 的话术。下文 Scene 卡逻辑不变，只是与脚本卡合并到一页。

**V2 现状**：三栏（左 LIVE Flow / 中 Set up scenes 的 Scene 卡 / 右 9:16）；Scene 卡二选一 radio：`Use avatar`（方式1 三层合成）/ `Use your video`（方式2 商家素材）；Overlay foreground 上传；浅绿"AI 已自动生成 storyboard"banner。

> **素材库弹框「我的片段」按上下文推荐（Log 0035）**：弹框从「某商品的某 Scene/卖点」点入，平台已知品+卖点上下文，故「我的片段」**默认推荐与该商品+该卖点最强相关的 clip**（卖点关键词命中权重最高），并支持语义搜索；无匹配则空态。片段预览抽屉展示**视频规格**（分辨率/帧率/编码/大小）。

> **左栏 `LIVE Flow` 结构约定**：一场直播 = **一个开场文案 + 商品列表 + 一个结尾文案**；商品列表是商家在 Step2 选中的品；`Set up scenes` 是围绕**一个品的多个卖点**展开，**一个卖点 = 一个 Scene**。即 `Opening → 品1(Scene×N) → 品2(Scene×N) → … → Closing`。

**V3 增量**：在 V2 的两个上传/选择入口上**挂载素材库弹框**（不改三栏布局、不改二选一逻辑）。**方式1 与方式2 打开的是同一个素材库弹框**（同一份商家素材库，不是两个独立弹框）：
- 方式1 子行 `Background: 🪑Default ✏️` → 点 ✏️ 先选**背景类型**（纯色/预设场景 · 图片上传 · **视频**）；选「视频」即打开**同一个素材库弹框**挑 clip 当背景（背景视频回填后子行显示 🎬 缩略图 + "视频背景"标）。
- 方式2 `Use your video` → 点缩略图区/`Upload` 打开**同一个**素材库弹框。

### 素材库弹框（复用 V2 弹窗 + 可选卡片 + dropzone + 分页）

弹框内**全部是商家自有素材，无平台公共库**（不设 `Templates` Tab）。**方式1/方式2 共用此弹框**，按**素材类型**分两个 Tab：

- **Tab① `Raw 原始素材`（类型1）**：未经加工的原片，含——
  - 方式1 `Background` 上传的视频 + 方式2 `Use your video` 上传的视频（**二者都算视频素材**；同一条素材**既可当前景、也可当背景**）；
  - 商家 **TikTok 账号已发布的短视频**（自有账号，授权拉取）。
- **Tab② `Clips 视频片段`（类型2）**：平台对"类型1 原片 + 直播录屏"做**自动分镜 + 画面理解 + 打标**后产出的 **clip 维度**素材（每段是可直接复用的标准片段）。
  - **clip 详情**：卡片可展开/悬浮查看——**时长、主打商品卖点、推荐用途、匹配度**，商家不必猜这段在讲什么。
  - **商家备注反馈**：商家可对某条 clip **添加备注**（如"这段口播很好/这段背景偏暗"）回流平台——这是除"改脚本→Save"外的**第二条喂数据通道**，平台据此优化解析与打标。
- **顶部语义搜索框**：输入关键词（卖点/场景/品类）即可跨 Tab 检索，尤其 `Clips` 片段极多时商家不用逐页翻账号 clip。
- （规划，V3 暂不开放）`Creator videos`：达人为商家商品带货产生的视频——属他人内容，**需达人逐条授权**方可入库，列为后续扩展（见平台端 §2 授权说明）。
- 网格：可选卡片（选中 teal+✓）+ 缩略图右下 **时长 badge** + 标题（`Clips` 卡额外展示 推荐用途/匹配度）。
- 右上 `+ Upload`（dropzone：虚线框 + ↑ + 规则提示，沿用 V2 方式2 规范 `MP4 ≤700MB / 5s~15min / ≥1080p / ≥24fps / H.264`）。
- **上传去重校验**：上传时做**重复度校验**，若该素材历史已传过，则**不重复入库**，直接在网格里标出该素材的**历史上传时间**，商家无需重传。

- 底部 `Cancel` / `Use selected`（teal）。
- 删除/替换/切换方式 1↔2 → **二次确认弹窗**（V2 既有，提示将清空已配置三层布局/素材/清洗稿）。

### 画面布局模型（V3 = 把 V2 三层从"固定参数"变成"商家可调"）

⭐ **Log 0036：去掉滑杆面板，改为直接在预览画面上操作**——商家直接在 9:16 预览里**拖拽数字人 / 前景贴片移动位置、拉角点圆点缩放**（所见即所得，保留「重置」）。**V3 不做 4 类 layer 用途下拉、不做 PIP 画中画**，只把 V2 已有的三层 + 数字人位置开放为商家可调：

> 与 V2 关系：V2 已有"远/中/前景三层 + X/Y/Scale"，但 V2 是**固定参数、商家不可调**；V3 的**唯一核心增量就是把这三层 + 数字人位置的调整能力开放给商家**，不引入 PIP、不引入 layer 用途选择。**选中某 Scene 调整布局时，右侧 9:16 `Preview` 实时渲染同步**，所见即所得。

### 商家输入新增

### 图片识别点（平台侧，商家无感）

## §6 模式一 · Generate scripts（**话术 List**，并入 §5 合并页）【P0】

> ⭐ **Log 0035 起：本节不再是独立 Step4，而是合并进 §5 的 `Set up scenes & scripts` 一页**——每个 Scene 卡内**内嵌**该 Scene 的话术，提供「✨ 重新生成」（带进度条）。话术由 **HOOK/BODY/CTA 分段**组成：**每段内容可改、整段可删、可「+ 加一段」，段标签本身也可改/可删**。
>
> ⭐ **Log 0036：话术改为「按动作触发生成」，不再预生成**——① **数字人讲（Use avatar）**：Scene 卡话术区初始为「✨ 生成脚本」按钮（提示"配好背景后点"），点击走分阶段进度条后生成、再编辑；② **用你的视频（Use your video）**：选完视频片段后**自动从该视频解析出口播话术**（进度条：读画面 → 识别原声 → 整理成可编辑话术）。两种方式生成后均回到可编辑分段。
>
> **本节属模式一（经典分步）**。模式一**不提供 List⇄Timeline 切换**（Log 0023）。多轨 Storyboard / timeline 是**模式二**的形态，见 §6.5。

**V2 现状**：三栏；中栏 `Scripts (N)` + `Show scripts in Chinese`；每 Scene 脚本卡（缩略图+标题+⏱ Estimated Duration + Hook/Body/CTA 三段 pill）；进入即**默认预填到"可发布"水位**；编辑能力（本期主覆盖编辑）；改文案实时合规高亮违禁词；Save/Previous/Next。

## §6.5 模式二 · **LIVE Storyboard**（Step3+Step4 合并为一步 · timeline 视图）【P2】

> **本节属模式二（智能剧本）**，把 §5 Set up scenes 与 §6 Generate scripts **合并为一个时间轴页**，由**平台端 Script Studio 主-子 Agent 编排**驱动（详见平台端 §3）。**架构本期先设计，实现后置 P2**；商家选模式二后进入此页（P2 上线前卡片置灰 `Coming soon`）。Step5 维持不变。

**入口与定位**：模式二跳过"先 Step3 再 Step4"的分步，直接进 **LIVE Storyboard**——一屏把口播/画面/互动/运营/声音/场外音多轨道原子**对齐到同一条时间轴**，商家在一个视图里掌控全场节奏。外层仍是 V2 三栏（左 LIVE Flow / 中 Storyboard / 右 9:16），色彩复用 V2 四态/中性灰，不新造色。

> ⭐ **核心模型：同一时间轴、多轨道叠加（非线性编辑器 NLE 式）**。这是模式二/剧本最核心的能力——**任一时刻可多轨同时生效**（如某 30s 内：轨1 口播 + 轨2 画面 + 轨5 场外音催单 + 轨6 铃声同时在响），不是"一轨接一轨顺序播"。详见下「多轨并发模型」与平台端 §3 直播大脑 JSON schema 契约。

### UI 展示逻辑（中栏 · LIVE Storyboard，横向时间轴，多轨泳道）
- **泳道布局**：横向一条绝对时间轴（秒），下方每条轨道一条独立 **lane**；先在轴上给**每个品分配时间段**，品内再排 Scene；各轨原子是 lane 上的色块，**带显式起止 `[start,end]`**，可拖拽改时点/时长、可在同一时间窗重叠。
- 轨道① **Speech 口播**：Hook / Body / CTA 段（pill 沿用 V2 灰），可编辑 ✏️；命中违禁词 highlight。**Scene 展示时长 = 该段口播 TTS 时长驱动**（§6.6）。
- 轨道② **Visual 画面**：方式1 三层布局缩略 / 方式2 **scene 素材 clip**（商家在 `Use your video` 上传的预录视频片段，画面走该 scene、TTS 解说不断），与素材库联动只读展示。**"画中画"效果用三层实现**——数字人作为中景缩小+定位、素材铺背景或全屏覆盖，**不引入独立 PIP 控件**；画面状态对应 `visual.layer`：`none`（数字人+背景同框）/ `foreground`（素材全屏覆盖、数字人隐）/ `background`（素材铺背景）。
- 轨道③ **Interaction 互动（独立模块）**：互动**不绑定到每个 Scene**，抽成**独立互动配置模块**，按**整场 / 商品维度**统一配置主动评论/问答楔子等"互动原子"；时间轴上只读展示落点，独立模块统一 on/off。
- 轨道④ **Operation 运营 ＝ 品级 overlay 层**：每个品一个 overlay 层，层内可放**多张图片元素**（商品实拍图贴前景"桌面"、价格牌/秒杀价/倒计时贴片贴画面左侧）。各元素 X/Y/Scale 可拖拽（沿用 V2 前景能力），**元素种类不封顶，由商家自行判断**。与脚本时间轴联动，只读+开关。
- 轨道⑤ **Voice 声音**：默认带 Step1 所选数字人音色；理想态支持**按商品差异化声纹/语速**（本期占位）。
- 轨道⑥ **Off-screen 场外音（强化真人在场，对冲红线 #15）**：任意时点 `+` 加**场外音原子**，二选一：① **音效库 SFX**（铃铛🔔/掌声/上新提示音/倒计时滴答…）；② **TTS 语音播报**（输入文案→选播报音色，**可与主播不同＝第二人声**→平台生成）。每原子可设**触发时点**（对齐时间轴/绑定某 Scene/运营节点）、**音量**、**是否压低 BGM（ducking）**。
- Scene 卡头部保留 ⏱ `Estimated Duration` + 预估脚本字数。

### ⭐ 多轨并发模型（同一时间轴叠加 · 渲染契约，与平台端 §3 schema 一致）
- **层级**：主时间轴(整场) → 品时间段(每个品一段) → 品内 N 个 Scene → 每条轨道独立泳道；原子 `{track, start_sec, end_sec, payload}`，靠**绝对时间对齐**、可重叠。
- **视觉合成（z-order，上→下）**：① 运营 overlay 元素（价格牌/倒计时/商品图）② 前景贴图 ③ 数字人（中景，缩放+定位 ＝ 画中画来源）④ 背景素材（scene clip）⑤ 全局背景。
- **音频混音（优先级 + ducking，高→低）**：① 口播 > ② 场外音 TTS（第二人声）> ③ SFX/铃声 > ④ BGM；高优先级活跃时自动压低低优先级（ducking）。
- **示例（消费者视角的一段并发）**：`t=0~8s` 轨1口播 + 轨2画面(数字人画中画) + 轨3互动 → `t=8~12s` 轨1口播 + 轨5场外音催单 + 轨6铃声(BGM duck) → `t=12~18s` 画面切轨2全屏素材(引导下单, layer=foreground) → `t=18s+` 轨1口播 + 轨2背景视频(layer=background)。
- **商家编辑形态**：拖动品时间段 → 品内拖各轨原子 start/end → 右侧 9:16 实时按上述合成/混音契约预览。

### 唯一"喂数据"动作 = 改 → Save（同模式一）
- 商家在口播轨编辑、开关互动/运营/场外音原子 → `Save` 回流平台；diff/归因全在平台端，商家无感。

**埋点回流**：`s4_script_edit`、`s4_interaction_toggle`/`s4_operation_toggle`（atom_id、on/off）、`s4_overlay_edit`（品 overlay 元素增删/拖拽）、`s4_offscreen_add`（type=sfx/tts、触发时点）、`s4_compliance_hit`、`s4_save`。**全部带 `mode=smart` 维度**，供平台端按模式归因。

## §6.6 Scene 时长由 TTS 驱动（两模式通用）

- **Scene 展示时长 = 该 Scene 口播脚本对应的 TTS 语音时长驱动**（与百度慧播星一致）。商家改脚本字数 → TTS 时长变 → 时间轴 Scene 段长**自动伸缩**，无需手填时长。
- **方式2 `Use your video` ＝ scene 素材**：商家上传的预录视频片段即一个 scene 的画面，渲染时**画面走该 scene、TTS 解说不断**；与 V2「Use your video」链路本就对齐，无需新概念（商家端 / 平台运营**统一口径叫 scene**，不再用"切镜"一词）。
- **不做"暖场/水军"**：不引入虚假暖场互动话术（规避无效互动红线 #12~14）。
